### 3.2 ~~Direct test coverage for `core/translate/workflow.py` (Q5)~~ — DONE 2026-09-13
The premise was stale: `tests/core/translate/test_workflow.py` already existed (app/`_Chunker`/node-level unit + property tests). What was still missing — and is now added — is the **loop-level** coverage: translate→evaluate→retranslate convergence with feedback injected into the rebuilt prompt, max-attempts-exhaustion keeping the *best* attempt (not the last), error-marker revert to the best earlier attempt, `failed=True` when errors exhaust attempts, `run_translation` raising `TranslationError` on a failed chunk state, and two tests through the **real compiled LangGraph app** (`importorskip("langgraph")`; green locally with the `async-translation` extra synced, runs in nightly).

**Latent bug found and fixed:** the compiled graph's nodes are `async`, so LangGraph's sync `app.invoke` raises `TypeError: No synchronous function provided` — meaning the public `run_translation` convenience entry (and `translation_app.invoke`) could never run the real graph. `workflow.py` now routes both through `_invoke_app`, which always uses `ainvoke` and bridges via a worker thread when an event loop is already running (production is unaffected — the translate plugin uses `translate_tree`, and only probes `get_translation_app()` for availability). Verified: 26/26 workflow tests, `tests/core/translate` + `tests/plugins/test_translate_service.py` 153 passed, ruff check/format clean, `mypy src` clean (220 files).
